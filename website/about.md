The FunGen-xQTL Computational Protocol is developed for the NIH/NIA Alzheimer's
Disease Sequencing Project (ADSP) Functional Genomics xQTL Consortium (FunGen-xQTL)
by its Analysis Working Group. It collects the pipelines the consortium uses to map
molecular QTL across brain tissues and cell types and to connect them to Alzheimer's
disease genetics, written so that other studies can run the same analyses on their
own data.

## Protocol reference

- [Where to get reference data](reference_data_sources.md): genome, annotation and LD reference sources.
- [Methods and references](methods_and_references.md): the methods used by each module and the papers to cite.
- [Glossary](glossary.md): definitions of the terms used throughout the protocol.

## Related FunGen-xQTL sites

- [Resources](https://adsp-fgc.niagads.org/xqtl-resources/): the consortium's datasets and results, and where to get them
- [AD Loci Explorer](https://xqtl.niagads.org/AD-loci-explorer/): AD GWAS loci linked to their candidate target genes
- [xQTL Atlas](https://xqtl.niagads.org/): the NIAGADS portal for FunGen-xQTL data

## Questions and contributions

Report a problem or ask a question on
[GitHub Issues](https://github.com/StatFunGen/xqtl-protocol/issues). Changes to a
module are made through a pull request against the notebook in `code/SoS/`.
