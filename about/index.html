About

The FunGen-xQTL Computational Protocol is developed for the NIH/NIA Alzheimer’s Disease Sequencing Project (ADSP) Functional Genomics xQTL Consortium (FunGen-xQTL) by its Analysis Working Group. It collects the pipelines the consortium uses to map molecular QTL across brain tissues and cell types and to connect them to Alzheimer’s disease genetics, written so that other studies can run the same analyses on their own data.

Reference pages¶

  • Where to get reference data, under Reference data: genome, annotation and LD reference sources.

  • Methods and references, under Reference: the methods used by each module and the papers to cite.

  • Glossary, under Reference: definitions of the terms used throughout the protocol.

Related FunGen-xQTL sites¶

  • Resources: the consortium’s datasets and results, and where to get them

  • AD Loci Explorer: AD GWAS loci linked to their candidate target genes

  • xQTL Atlas: the NIAGADS portal for FunGen-xQTL data

Questions and contributions¶

Report a problem or ask a question on GitHub Issues. Changes to a module are made through a pull request against the notebook in code/SoS/.
